## 1. 率定方案

本轮 SM 率定不修改原 `case02_ChinaFlux_CMFD.jl`，新建脚本在 CMFD V4 通量率定结果基础上继续优化土壤水分参数。

基本流程：

1. 读取 `NSE_CMFD_1h_V4/BEPS_<site>.jld2` 中的通量率定参数 `theta_opt`，作为模型初值。
2. 将土壤导水率剖面改为 `KvExp`：
   `Ksat(z) = kv * exp(-f * z)`。
3. 仅优化 SM 相关水力参数：
   - 观测深度对应土层的 `theta_sat` 分层优化；
   - `psi_sat` 全层共用 1 个值；
   - `b` 全层共用 1 个值；
   - `KvExp` 优化 `kv` 和 `f` 两个参数。
4. 默认目标函数为 `SM_GOAL = KGE`。

该方案将参数维度控制在较小范围内，避免逐层优化 `Ksat / psi_sat / b` 导致参数过多、不可辨识。

## 4. 结果判断

本轮 SM 优化没有带来稳定的综合精度提升。

主要现象：

- `bias` 和部分深度的 `RMSE` 有改善，说明参数调整确实在修正土壤水分量级。
- `R2` 显著下降，说明动态过程、季节相位或降雨响应被破坏。
- `KGE` 和 `NSE` 的改善不稳定：多数深度点略有改善，但少数站点大幅恶化，导致整体均值变差。

因此，本轮默认 `KGE` 目标函数更倾向于修正均值和幅度，但未能保护 SM 时间动态。

## 6. 建议

下一轮不建议继续使用单纯 `KGE` 作为 SM 目标函数。

建议改为保护动态过程的目标函数，例如：

```text
loss = -mean(R2) + lambda * mean(abs(relative_bias)) + mu * mean(RMSE)
```

优先级：

1. 保住 `R2`，即干湿变化相位和季节动态；
2. 用 bias penalty 修正量级；
3. 用 RMSE penalty 控制幅度误差；
4. 对水田、湿地、灌溉站点单独处理，不与自然排水站点共用同一 SM 率定逻辑。

同时建议加入观测筛选：

```text
sd(SM_obs) 足够大
baseline R2 不接近 0
n_valid 足够多
```

其中 `baseline R2` 需要先用 CMFD V4 初值跑一次模拟，再用 `cor(SM_obs, SM_sim)^2` 计算；`sd(SM_obs)` 只用于判断观测本身是否有足够动态信号。
